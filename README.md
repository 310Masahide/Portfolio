### 開発にあたって
---
*当作成者の精神的疾患に罹患した経験から、日頃の辛い出来事やストレスに繋がる出来事を打ち込むことで
　Aiがそれに対して俯瞰的にコメントを返し意味のある出来事であったと指摘しより良い生活を送るヒントに導きます。
*既存の日記アプリや認知行動療法アプリと機能が酷似する点があるかもしれませんが、温かい目でご覧いただければ幸いです。
### 概要
---
*今日起きた出来事をフォームに入力し「AIに俯瞰してもらう」ボタンを押下することで入力内容を俯瞰しコメントしてくれます。
*前日以前に入力した内容は履歴ボタンを押下すると履歴として残っており、必要に応じて出来事毎に削除することもできます。
